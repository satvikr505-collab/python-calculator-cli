# Python CLI Calculator

## Description

This project is a command-line calculator developed using Python.

It supports the following basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

The program uses functions, loops, conditionals, and user input.

## Features

- User-friendly command-line menu
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Continuous operation until the user selects Exit

## Technologies Used

- Python
- VS Code
- Command Line / Terminal

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:
5. Select an operation from the menu.
6. Enter the required numbers.
7. Select option 5 to exit.

```bash
python calculator.py
